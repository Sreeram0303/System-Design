# System Design Interview — Study Notes

Working through **[System Design Interview: An Insider's Guide](https://www.amazon.com/dp/B08CMF2CQF)** by Alex Xu, chapter by chapter — writing up what actually clicked along the way, not just summarizing the text.

This repo doesn't include the book itself (see [Note on copyright](#note-on-copyright) below) — grab a copy to read alongside these notes.

## What's here

Each chapter gets a paired set of notes in [`notes/`](notes/):

- **`chapter-NN-<slug>.md`** — the core mechanism, worked examples, and the reasoning behind each design choice.
- **`chapter-NN-<slug>.html`** — a companion visual version of the same chapter, with diagrams for the parts that are easier to understand drawn than described: architecture flows, hash rings, bit layouts, quorum overlaps, and more. Open it directly in a browser.
